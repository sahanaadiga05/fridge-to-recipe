# Fridge to Recipe

Fridge to Recipe is an AI-powered recipe generator. Enter the ingredients available in a fridge and the app creates a practical, dish-specific recipe with quantities, substitutions, serving controls, and step-by-step cooking instructions.

## Features

- Interactive illustrated fridge landing experience.
- Ingredient input form with an animated kitchen-style interface.
- AI-generated recipes based on the user's ingredients.
- Recipe title, description, difficulty, ingredient quantities, and cooking steps.
- Serving controls that scale ingredient amounts.
- Ingredient substitution options that also update the displayed cooking steps.
- Checkable cooking steps with progress tracking.
- Responsive React interface with animated transitions.
- JSON validation, retry handling, and friendly error messages for invalid AI responses.

## Tech Stack

- React 19 and Vite
- Express 5
- Google Gemini via `@google/genai`
- Zod for recipe-response validation
- Framer Motion for UI animation
- Lucide React for interface icons

## Setup

### Prerequisites

- Node.js 20 or newer
- A Gemini API key from Google AI Studio

### 1. Install dependencies

```bash
npm install
```

### 2. Add the API key

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3001
```

Do not commit `.env`; it is already included in `.gitignore`.

### 3. Start the app

```bash
npm run dev
```

This starts both services together:

- Frontend: `http://localhost:5173`
- Recipe API: `http://localhost:3001`

## Usage

1. Open the fridge landing screen and interact with the door.
2. On the recipe screen, enter ingredients separated by commas, for example: `rice, eggs, tomato, onion, cheese`.
3. Select **Create a recipe**.
4. Wait for the AI to return a recipe.
5. Change the serving count, adjust quantities, use **Swap** for substitutions, and tick steps off while cooking.

## Known Limitations

- Recipe quality depends on the Gemini API response and the supplied ingredients.
- The API request requires an internet connection and a valid Gemini API key.
- Requests have a 15-second server timeout. If Gemini is slow or unavailable, the user can select **Try again**.
- A recipe supports up to 20 ingredients and up to 10 cooking steps.
- Ingredient amounts are generated by AI and can still need a practical user check before cooking.
- The Gemini API key must be configured as a Vercel environment variable for deployed recipe generation to work.

## Vercel Deployment

The project includes a Vercel Function at `/api/generate-recipe`, so the deployed frontend and API run under the same domain.

1. Push the repository to GitHub.
2. Import the repository at [Vercel](https://vercel.com/new).
3. Select the `Vite` framework preset, use `npm run build` as the build command, and use `dist` as the output directory.
4. Add `GEMINI_API_KEY` in Vercel Project Settings under Environment Variables.
5. Deploy and test recipe generation from the production URL.
